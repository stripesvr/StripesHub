## Using the site

| | |
| --- | --- |
| **Click to Enter** | Starts the music. The track keeps playing as you move between pages. |
| **Search** | On pages with a search box, press `/` to jump to it, and `Esc` to clear it. |
| **Copy** | Command buttons copy the text straight to your clipboard. |
| **Hover** | Buttons and cards tilt toward your cursor. |
